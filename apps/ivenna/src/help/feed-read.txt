ivenna feed read FEED_ID [--after SEQUENCE] [--limit N]

Pass the exact feed ID Ivenna provided as one shell argument.

  ivenna feed read 'releases-1' --after 17

--after selects messages with a sequence greater than the supplied number
(default 0). --limit defaults to 100 and accepts 1 through 1000.

A successful read writes one page as a JSON line on stdout. The page contains
feed_id, description, closed, messages, next_after, and has_more. Messages
are in ascending sequence order. Each message has sequence, focus_id, text,
and published_at_unix_ms.

After processing the whole page, save next_after and pass it as --after on
the next read. An empty page keeps the supplied position. When has_more is
true, read the next page. When has_more is false, poll later for an open
feed or stop for a closed feed.

For an unknown feed, stdout contains "unknown_feed" and the exit status is 1.
