ivenna-report inspect SUBSCRIPTION_ID

Read the registration and saved cursor as JSON on stdout.

  "$IVENNA_REPORT" inspect releases-1

An active subscription returns an object with subscription_id, focus_id,
listener and cursor. A null cursor in that object means the listener has yet
to save a position. If the entire result is null, the ID is unknown or has
been withdrawn. Both results have exit status 0.
