# Ivenna

Ivenna 是一个面向长期运行的 AI agent，探索如何通过持续会话与自主记忆“维持自我”。

后续输入可以接续已有会话；Ivenna 也可以自行组织、读取和调整记忆，在不同会话间继续使用这些信息。

## 当前状态

项目仍处于原型阶段，目前通过 HTTP 服务接收输入、处理会话并保存历史，交互方式和记忆管理仍在迭代。
